# Portfolio

Personal portfolio and project showcase built with the full **T3 Stack**.

**Live:** [shayanali.vercel.app](https://shayanali.vercel.app)

## Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **API:** tRPC
- **Database:** Prisma + Turso / SQLite
- **Styling:** Tailwind CSS + shadcn/ui
- **Auth:** NextAuth.js

## Features

- Clean, modern, responsive design
- Dark / light mode
- Projects section powered by GitHub API
- Skills showcase
- Fully type-safe end-to-end

## Getting Started

```bash
git clone https://github.com/ShayanAliProgrammer/Portfolio.git
cd Portfolio
bun install
cp .env.example .env
bun run dev
```
